
2. cd react_redux_reducer_selector
3. npm install or yarn install

## 🔍 Key Concepts

### 🎯 Reducers

Reducers are pure functions that define how the application's state changes in response to an action. Find them in the src/redux/reducers/ directory.

🔑 Selectors
Selectors encapsulate and simplify access to the Redux state, improving reusability and maintainability. Explore the src/redux/selectors/ folder for examples.

### 💻 Usage

Add a Reducer:

Define a reducer function for new application features.
Combine it with existing reducers using combineReducers.
Use a Selector:

Create a selector function to extract specific data from the Redux store.
Use it in components to display the required data.
Dispatch Actions:

Trigger state updates by dispatching actions from your React components.
